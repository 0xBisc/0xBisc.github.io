02. Reading the Filename with Spaces & Leading Dashes

If we try running cat --spaces in this filename-- directly, it returns an error because the arguments aren't handled as a single quoted filename starting with dashes:

bandit2@bandit:~$ cat --spaces in this filename--
error: unexpected argument '--spaces' found

  tip: to pass '--spaces' as a value, use '-- --spaces'

Usage: cat [OPTION]... [FILE]...

For more information, try '--help'.

To read it properly, we need to build on what we learned in the previous level, while also keeping in mind that spaces in the filename need to be grouped—by wrapping the filename in double quotes ("--spaces in this filename--").

Using the full path with the filename inside quotes:

bandit2@bandit:~$ cat /home/bandit2/"--spaces in this filename--"
7ZZ2LFrykP2zEyvBl4m3clcL7tGYJPME

Or using a relative path with ./:

bandit2@bandit:~$ cat ./"--spaces in this filename--"
7ZZ2LFrykP2zEyvBl4m3clcL7tGYJPME

A third option is using -- before the quoted filename, which tells cat to stop parsing command-line options so any following arguments are treated strictly as filenames rather than flags:

bandit2@bandit:~$ cat -- "--spaces in this filename--"
7ZZ2LFrykP2zEyvBl4m3clcL7tGYJPME

There are other ways to read it too—pick whichever method you prefer, and make sure you understand what the command does before running it.
