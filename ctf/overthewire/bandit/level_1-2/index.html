02. Reading the - File

If you try running cat - directly, it can look like your device lagged or an error happened—but nothing is broken. A standalone - tells cat to read from standard input (your keyboard or piped input) instead of a file named -.

To read the file properly, pass a path to it—either the full path:

bandit1@bandit:~$ cat /home/bandit1/-

bandit1@bandit:~$ cat ./-

There are other ways to read it too, so pick whichever you prefer—just make sure you understand the command before running it.
