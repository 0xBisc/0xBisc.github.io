// About OverTheWire — Bandit

Platform: OverTheWire · Track: Bandit · Difficulty: Beginner

Bandit is the starting wargame on OverTheWire, built specifically for anyone getting comfortable with the Linux terminal and SSH. Rather than jumping straight into complex exploitation, each stage focuses on practical command-line skills—navigating filesystems, inspecting permissions, filtering text, and working with processes and basic networking.

// How the Levels Work

The game is structured sequentially starting at Level 0. Solving a stage gives you the password needed to log into the next user account over SSH (for example, beating Level 0 unlocks the credentials for bandit1). Every level page explains how to reach that target from the previous stage.

// Approach When Stuck

Getting stuck is part of the process—the goal is to build the habit of reading documentation and testing commands rather than guessing:

  • Read the manual: Run man <command> (such as man ls or even man man) to check flags and usage. Press / to search inside a man page, n / N to jump between matches, and q to quit.
  • Check shell built-ins: Some commands like cd don't have a separate man page—use help <command> instead.
  • Search & research: Look up unfamiliar concepts, error messages, or file formats to understand how Linux handles them under the hood.

Don't give up on a level — read the man pages, test your commands, solve it and earn that biscuit! No persistence means no biscuit 🙃🍪

[!] VM Networking Tip (SSH Broken Pipe)

If you connect from a virtual machine using NAT mode and run into an SSH broken pipe error, add IPQoS throughput to /etc/ssh/ssh_config. If that doesn't clear it up, switch your VM network adapter from NAT to Bridged mode.

// Tip

Create a file for notes and passwords on your local machine. Passwords for levels are not saved automatically, so if you do not save them yourself, you will need to start over from bandit0. Passwords also occasionally change, and detailed notes help you return where you left off, reference later problems, or help others after completing a challenge.
