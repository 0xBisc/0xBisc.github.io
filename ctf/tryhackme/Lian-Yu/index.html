Lian_Yu — Room Walkthrough

Lian_Yu is an Arrow-themed TryHackMe challenge set on the remote island of Lian Yu. Rather than relying on a single exploit, the machine chains together multi-stage web directory enumeration, hidden HTML inspection, Base58 decoding, FTP exploration, PNG header repair, steganography extraction, SSH login, and privilege escalation via pkexec.

02. Discovering the Ticket & Decoding the FTP Password

Visiting http://10.112.163.166/island/2100/ showed an unavailable YouTube video and the prompt "How Oliver Queen finds his way to Lian_Yu?". Nothing obvious appeared on the rendered page, so I opened the source code/inspector and found an HTML comment pointing to a custom .ticket extension:

<!-- you can avail your .ticket here but how?   -->

Because the comment specifically asked how to get a .ticket "here" (inside /island/2100/), I ran gobuster on that exact path with -x ticket:

┌──(bisc㉿kali)-[~]
 └─$ gobuster dir -u http://10.112.163.166/island/2100/ -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x ticket

green_arrow.ticket   (Status: 200) [Size: 71]

Gobuster quickly returned green_arrow.ticket.

File Name Found (Flag 2): green_arrow.ticket

Accessing http://10.112.163.166/island/2100/green_arrow.ticket revealed a short note and an encoded string:

This is just a token to get into Queen's Gambit(Ship)


RTy8yhBQdscX

Trying RTy8yhBQdscX directly as the password for vigilante on FTP failed. Suspecting a Base encoding format (such as Base32, Base45, Base58, Base62, Base64, or Base85), I tested the string in CyberChef ↗ and found that decoding it as Base58 produced !#th3h00d.

Testing vigilante with !#th3h00d on FTP succeeded, confirming the FTP password.

FTP Password (Flag 3): !#th3h00d

I noted slade and exited FTP. When opening the downloaded images locally, Queen's_Gambit.png and aa.jpg displayed properly, whereas Leave_me_alone.png failed to open. Inspecting Leave_me_alone.png in hexeditor revealed that the first six bytes of its PNG signature were corrupted (58 45 6F AE 0A 0D instead of the standard PNG header 89 50 4E 47 0D 0A 1A 0A):

# Corrupted bytes at offset 0x00000000
00000000  58 45 6F AE  0A 0D 1A 0A   00 00 00 0D  49 48 44 52  XEo.........IHDR

# Fixed PNG header bytes
00000000  89 50 4E 47  0D 0A 1A 0A   00 00 00 0D  49 48 44 52  .PNG........IHDR

After updating the header to 89 50 4E 47 0D 0A and saving the file, Leave_me_alone.png opened normally and showed a man with a gun alongside text ending with the word password in larger red letters.

Trying slade with password on FTP and SSH did not work.
